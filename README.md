# Atomic Red Team Home Lab

Controlled MITRE ATT&CK technique emulation and detection validation for SOC Analyst skill development.

## Overview

This repository documents the use of Atomic Red Team to safely emulate attacker techniques in a Windows lab, then validate the resulting telemetry in Sysmon, Windows Event Logs, and Wazuh SIEM.

## What’s Included

| File | Description |
|------|-------------|
| `Atomic_Red_Team_Lab_Report.docx` | Portfolio lab report (Word) |
| `Atomic_Red_Team_Lab_Report.md` | Same report in Markdown |
| `Atomic_Red_Team_Lab_Guide.md` | Step-by-step setup and testing guide |

## Skills Demonstrated

- Installing and running Invoke-AtomicRedTeam
- Executing selected ATT&CK techniques safely
- Observing process creation and related telemetry in Sysmon
- Mapping activity to MITRE ATT&CK
- Assessing detection coverage and gaps
- Structured documentation of detection testing results

## Related Labs

Designed to work with the **Sysmon**, **Wazuh SIEM**, **Windows Event Log**, **Active Directory**, and **Wireshark** home labs.
